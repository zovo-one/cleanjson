CleanJSON by Zovo
The part nobody talks about

Pasting your API response into a random website is a habit worth breaking.

JSON on the web is dense, single-line, and ugly. So developers paste it into the first free formatter that ranks on Google. Most of those sites log what you paste. Your response bodies, error payloads, and customer records travel to a server you have never audited.

CleanJSON formats it in your browser. No tab opened, no request on the network, no clipboard sent anywhere. It is the version of that habit that does not leak.
